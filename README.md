# UTSegmentProject
<div dir="rtl">
پروژه دانشگاهی پیش‌پردازش تصاویر OCR و جداسازی کاراکترها

این پروژه با استفاده از تکنیک‌های کلاسیک پردازش تصویر، مراحل پیش‌پردازش تصاویر متنی و جداسازی کاراکترها را پیاده‌سازی می‌کند. در این فرآیند، تصاویر با انواع نویزها و فیلترها پردازش شده و پس از اعمال عملیات‌هایی مانند تبدیل به تصویر دودویی و پردازش مورفولوژیک، کاراکترها از یکدیگر تفکیک می‌شوند.

نکته: در این پروژه از هیچ مدل یادگیری ماشین، یادگیری عمیق یا الگوریتم‌های بینایی ماشین استفاده نشده و تمامی مراحل تنها بر پایه پردازش تصویر انجام شده‌اند.
